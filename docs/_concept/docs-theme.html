Introduction

A dark/light documentation theme built for CLI tools, web apps, and TUIs. Sharp corners, restrained accents, and a windowed-pane motif borrowed from the terminal.

Every code sample, callout, and panel in this theme shares the same chrome: a three-dot title bar, like a terminal multiplexer pane. It's a small detail that reads as native to the subject matter instead of decorative.

Note

This page doubles as a living style guide — every component you need for a docs site is demonstrated below.

Installation #

Install the CLI globally, then verify the version:

terminal 
# install
npm install -g @studio/docs-cli
# check
docs --version
Requires

Node.js 18 or later. Older runtimes are not supported.

Quick start #

Scaffold a new site and start the dev server:

config.json 
{
  "theme": "auto",
  "sidebar": true,
  "search": true,
  "port": 4321
}

Config options

KeyTypeDefault
themestring"auto"
sidebarbooleantrue
portnumber4321

Press Ctrl + K to open search once it's wired up. Everything scales fluidly — resize the window and watch the type and spacing respond via clamp() instead of fixed breakpoint jumps.

Breaking change

v2 renames sidebar.collapsed to sidebar.defaultState. Update any saved config before upgrading.

Tip

Set theme: "auto" to follow the reader's OS preference on first visit, then remember their explicit choice after that.
